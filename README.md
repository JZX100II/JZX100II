## Selected Projects

### [ITSMixer: Iterative Time-Mixing MLPs for Efficient Long-Term Forecasting](https://github.com/JZX100II/ITSMixer)

A lightweight, channel-independent MLP model for multivariate long-term time-series forecasting that relies solely on iterative time-mixing without feature-mixing layers.

- Improved average MSE by 3.51% compared with vanilla TSMixer across six benchmark datasets.
- Published in *Evolving Systems* (Springer), 2026.

### [Multi-Agent Indoor Mapping and Navigation](https://github.com/JZX100II/Multi-Agent-Indoor-Navigation)

A simulation-based multi-agent system for indoor mapping and autonomous navigation, combining visual perception, mapping, and path planning.

**Tools:** Python, Webots

### [Neural Image Upscaling](https://github.com/JZX100II/Neural-Image-Upscaling)

A PyTorch-based coordinate neural model that uses Fourier feature encoding with Fibonacci-inspired frequencies to represent image coordinates and render images at higher resolutions.

- Maps 2D image coordinates to RGB values.
- Uses multi-frequency sine and cosine features for coordinate encoding.

**Tools:** Python, PyTorch.

### [KD-Tree Implementation](https://github.com/JZX100II/KDTree)

A Python implementation of a KD-Tree data structure for efficient spatial organization and nearest-neighbor search.

**Tools:** Python
